# Single-Page HTML CV 

A clean, structured, and fully semantic single-page Curriculum Vitae (CV) built **strictly using HTML**. This project serves as a rock-solid foundation for a web-based professional profile, prioritizing accessibility, SEO best practices, and clean document structure before any visual styling is applied.

This project follows the guidelines from the [roadmap.sh Single-Page CV Project](https://roadmap.sh).
https://roadmap.sh/projects/single-page-cv

---

##  Project Goal

The primary objective of this project is to master **Semantic HTML** layout principles. By separating content structure completely from visual presentation, this CV is perfectly optimized for screen readers, search engines, and future styling with CSS.

---

##  Key Features & Requirements Met

*   **Semantic HTML Structure:** Developed using meaningful tags (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`) rather than generic divs.
*   **SEO Optimization:** Configured critical `<meta>` tags in the `<head>` section (description, keywords, author) to maximize search engine discoverability.
*   **Open Graph (OG) Tags:** Fully integrated OG meta tags to ensure beautiful link previews when sharing the CV on social platforms like LinkedIn, WhatsApp, or Twitter.
*   **Favicon Integration:** Included a custom shortcut icon linked natively in the header browser tab.
*   **Clean Architecture:** Highly organized layout separating **Education**, **Skills**, and **Career History** into scalable modules ready for CSS styling frameworks or vanilla CSS in upcoming iterations.

##  Semantic Layout Overview

The document is organized into logical nodes to preserve native document hierarchy:

*   **`<header>`**: Full name, current professional title, and structured contact channels.
*   **`Education Section`**: Semantic lists highlighting institutions, degrees, and timelines.
*   **`Skills Section`**: Grouped competencies displaying tech stacks and soft skills natively.
*   **`Work Experience`**: Chronological timelines leveraging detailed sub-sections for career duties.
